# 🔐 Tela de Login — Grana

![Tela de Login](./image(16).png)

## 📖 Descrição

A tela de login é o primeiro contato do usuário com o aplicativo **Grana**, uma plataforma de organização financeira baseada em conversas.

O objetivo desta tela é permitir um acesso rápido e simples, reforçando a proposta do produto: **"Suas finanças em uma conversa 🌈"**.

---

## 🎨 Layout

A interface possui um visual minimalista, moderno e acolhedor.

### Componentes

### Logo

- Nome: **Grana ✨**
- Posicionado no topo da tela.

---

### Mensagem de Boas-vindas

**Título**

> Bem-vindo de volta

**Subtítulo**

> Suas finanças em uma conversa 🌈

---

### Login Social

Botão:

```
Continuar com Google
```

Permite autenticação rápida utilizando a conta Google.

---

### Separador

```
──────── ou ────────
```

Indica que o usuário também pode utilizar login tradicional.

---

### Campos

#### E-mail

Placeholder

```
E-mail
```

---

#### Senha

Placeholder

```
Senha
```

---

### Botão Principal

```
Entrar
```

Cor predominante:

- Verde

Ação:

Realiza autenticação do usuário.

---

### Cadastro

Texto

```
Ainda não tem conta?
Cadastre-se
```

O link **Cadastre-se** direciona para a criação de uma nova conta.

---

# 💡 Experiência do Usuário

A tela foi pensada para transmitir simplicidade.

O usuário pode:

- Entrar com Google (mais rápido)
- Entrar usando e-mail e senha
- Criar uma nova conta

Tudo com poucos cliques.

---

# 🎯 Objetivo

Reduzir a fricção de entrada no aplicativo, permitindo que o usuário comece rapidamente a registrar suas finanças por meio de conversas com a IA.
